# Code Review assets

Reusable evidence templates:

- [review-report.template.md](review-report.template.md) — human-readable review report.
- [review-evidence.template.json](review-evidence.template.json) — machine-readable evidence/handoff shape.

Templates are starting structures, not a substitute for repository evidence. Do not copy placeholder values into a final report without replacing them with facts from the reviewed candidate.
